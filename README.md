# Go Plants

## Описание

Go Plants — это приложение для управления растениями с функционалом регистрации пользователей, авторизации и работы с JWT-токенами. В приложении реализованы основные функции для управления растениями, включая создание, обновление, удаление и получение информации о растениях. Также пользователи могут регистрироваться, авторизовываться и получать JWT-токен для доступа к личным данным.

## Структура проекта
Использована модульная архитектура с применением принципов MVC

- **internal/**
  - **admin/**: Административные функции и обработчики
  - **middleware/**: Промежуточное ПО для аутентификации и авторизации
  - **models/**: Модели данных
  - **plant/**: Функционал для работы с растениями
  - **user/**: Функционал для работы с пользователями
- **config/**: Конфигурация приложения и базы данных
- **main.go**: Точка входа в приложение

## Модели и таблицы

В проекте используются три основные таблицы:
- **users** - для хранения информации о пользователях
- **plants** - для хранения информации о растениях
- **user_plants** - для хранения информации растений пользователей

## База данных

- Используется **PostgreSQL** для хранения данных
- Реализованы миграции для создания и обновления таблиц
- Настроено подключение через GORM ORM
- Поддержка транзакций и связей между таблицами

## Функционал

### Пользователи
- Регистрация нового пользователя
- Авторизация с использованием JWT
- Получение профиля пользователя
- Обновление данных пользователя

### Растения
- Создание нового растения
- Добавление растений в личный кабинет
- Получение списка растений пользователя
- Обновление информации о растении
- Удаление растения
- Настройка параметров растений под свои потребности

### Административные функции
- Очистка таблиц
- Сброс автоинкремента
- Управление пользователями

## Маршруты и обработчики

### Публичные маршруты
- `POST /api/register` - регистрация нового пользователя
- `POST /api/login` - авторизация и получение JWT-токена

### Защищенные маршруты (требуют JWT-токен)

#### Профиль пользователя
- `GET /api/profile` - получение профиля пользователя
- `PUT /api/profile` - обновление данных пользователя

#### Коллекция растений пользователя
- `POST /api/my-plants/copy/:id` - копирование растения в коллекцию пользователя
- `PUT /api/my-plants/:id` - обновление названия растения в коллекции
- `GET /api/my-plants` - получение всех растений пользователя

#### Каталог растений
- `GET /api/plants` - получение списка всех растений
- `GET /api/plants/:id` - получение информации о конкретном растении

#### Управление пользователями
- `GET /api/users` - получение списка всех пользователей
- `GET /api/users/:id` - получение информации о конкретном пользователе

### Административные маршруты

#### Управление пользователями
- `GET /admin/users/count` - получение общего количества пользователей
- `PUT /admin/users/reset-id` - сброс автоинкремента ID пользователей
- `DELETE /admin/users` - удаление всех пользователей
- `DELETE /admin/users/:id` - удаление конкретного пользователя

#### Управление растениями
- `POST /admin/plants` - создание нового растения
- `GET /admin/plants` - получение списка всех растений
- `GET /admin/plants/:id` - получение информации о конкретном растении
- `PUT /admin/plants/:id` - обновление информации о растении
- `DELETE /admin/plants/:id` - удаление растения

## Технологии

- **Go 1.23+**
- **PostgreSQL** - система управления базами данных
- **Gin** - веб-фреймворк для обработки HTTP-запросов
- **GORM** - ORM для работы с базой данных
- **JWT** - для аутентификации и авторизации
- **bcrypt** - для хеширования паролей
- **Zap** - для логирования
- **Validator** - для валидации данных

## Требования

- Go 1.23+
- PostgreSQL
