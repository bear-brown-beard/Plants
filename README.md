# Go Plants

## Описание

Go Plants — это приложение для управления растениями с функционалом регистрации пользователей, авторизации и работы с JWT-токенами. В приложении реализованы основные функции для управления растениями, включая создание, обновление, удаление и получение информации о растениях. Также пользователи могут регистрироваться, авторизовываться, обновлять свой профиль и получать JWT-токен для доступа к личным данным.

## Структура проекта

- **models**: Модели данных, включая модель для растений и пользователей.
- **services**: Логика обработки запросов и взаимодействие с базой данных (например, создание пользователя, работа с растениями).
- **handlers**: Обработчики HTTP-запросов для регистрации, авторизации, работы с растениями и обновления профиля.
- **routes**: Регистрация маршрутов для работы с пользователями, растениями и аутентификацией.
- **auth**: Логика авторизации, включая работу с JWT-токенами, middleware для проверки токенов и генерацию новых токенов.
- **config**: Конфигурация базы данных и других компонентов.
- **admin**: Административные функции для очистки таблиц и сброса автоинкремента.

## Что сделано на данный момент

### Модели:
- **User**: Модель для пользователей с полями: имя, фамилия, email, пароль и город.
- **Plant**: Модель для растений с полями: имя, описание, дата последнего полива, пересадки, разведение и связь с пользователем.

### База данных:
- Используется **PostgreSQL** для хранения данных о пользователях и растениях.
- Реализована миграция для таблиц пользователей и растений.

### Основной функционал:
- **Регистрация пользователя**: Новый пользователь может зарегистрироваться с проверкой email и пароля, включая хеширование пароля.
- **Авторизация**: Пользователь может авторизоваться с использованием **JWT-токенов** для дальнейшего доступа к защищённым ресурсам.
- **Управление растениями**: Реализованы **CRUD-операции** (создание, получение, обновление, удаление) для работы с растениями.
- **JWT-аутентификация**: Защищенные маршруты с использованием токенов для доступа к личному кабинету и обновлению профиля.
- **Обновление профиля**: Пользователь может обновить своё имя, фамилию и город, при этом другие данные останутся неизменными.

### Маршруты и обработчики:
- **/register**: Маршрут для регистрации нового пользователя.
- **/login**: Маршрут для авторизации пользователя и получения JWT-токена.
- **/plants**: Маршрут для работы с растениями (создание, получение, обновление и удаление).
- **/profile**: Защищённый маршрут для получения и обновления информации о профиле пользователя (требуется авторизация).
- Административные маршруты: Для очистки таблиц и сброса автоинкремента.

## Технологии

- **Go 1.18+**
- **PostgreSQL** для хранения данных
- **Gin** для обработки HTTP-запросов
- **JWT** для авторизации и защиты маршрутов
- **GORM** для взаимодействия с базой данных
- **bcrypt** для хеширования паролей

## Требования

- **Go 1.18+**
- **PostgreSQL**
