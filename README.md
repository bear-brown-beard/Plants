# Go Plants

## Описание

Это приложение для управления растениями. На текущий момент реализованы основные функции работы с растениями, включая создание, обновление, удаление и получение информации о растениях. Также подготовлена структура для добавления пользователей, однако авторизация и личный кабинет еще не реализованы.

## Структура проекта

- `models`: Модели данных, включая модель для растений.
- `services`: Логика обработки запросов и взаимодействия с базой данных.
- `handlers`: Обработчики HTTP-запросов.
- `routes`: Регистрация маршрутов для работы с растениями.
- `config`: Конфигурация базы данных и других компонентов.
- `admin`: Административные функции для очистки таблиц и сброса автоинкремента.

## Что сделано на данный момент

1. **Модели**:
   - Модель растения (`Plant`), включающая поля для имени, описания, полива, пересадки и разведения.
   
2. **База данных**:
   - Используется PostgreSQL для хранения данных о растениях.
   - Подготовлена структура для добавления пользователей, но взаимодействие с ними еще не реализовано.

3. **Основной функционал**:
   - Добавление, получение, обновление и удаление растений.
   - Очищение таблицы растений и сброс автоинкремента через административные функции.

4. **Маршруты и обработчики**:
   - Реализованы маршруты для работы с растениями (`/plants`), включая операции POST, GET, PUT и DELETE.
   - Административные маршруты для очистки таблиц и получения количества растений.

## Требования

- Go 1.18+
- PostgreSQL
